# 论文上传与最终交付网站

更新日期：2026-09-26。网站支持本机执行和云端接收、本地工作机执行两种配置。部署操作记录位于仓库外，凭据不写入本文。

## 用户流程

首次访问时显示“亲爱的通信人，你好！”欢迎说明，介绍大创团队、多智能体分工、缺参假设、复现局限、硬件提醒、当前 DeepSeek V4.1 Flash 模型、作者承担 token 费用，以及 `lisongjun020@gmail.com` 反馈邮箱。点击“我已了解，开始使用”后在当前浏览器记住该版本；直接关闭或按 Escape 仅关闭本次展示。右上角“使用说明”可随时重新打开，登录前后均可用。此说明不是注册条款或额外的流程审批，不要求滚动到底或勾选选项。

说明使用原生模态对话框处理焦点与键盘，正文独立滚动、底部操作保持可见。浏览器存储不可用时仍能关闭使用。重要文案变更时更新 `App.tsx` 中的通知版本，使已读用户能看到新版说明。

1. 使用邮箱和密码注册、登录。
2. 上传 PDF，可选填写论文名称。服务创建归属于该账号的案例；本机模式调用原有 `ReviewPipeline`，pull 模式排队等待本地工作机领取。
3. 在“我的论文”查看简单状态：待处理、处理中、已完成、待继续处理、已停止。
4. 完成后点击“下载交付包”，获得两份中文 Word 报告及分任务复现项目。

运行中的列表每 15 秒刷新一次，页面隐藏时暂停刷新；不再显示百分比、阶段时间线、逐任务核验、执行事件、在线报告或中间文件。关闭浏览器或退出登录不会停止后台作业。用户可以主动停止，失败或停止后可以继续处理。

## 视觉与品牌

页面使用“BUPT 耿同学 · 通信论文复现”作为品牌，延续浅色界面，以雾蓝背景、蓝色主按钮、青色和暖色图标区分交付内容。登录页以通信主题插画和横向交付说明介绍用途；登录后的研究空间保留论文上传、简单任务状态及最终 ZIP 下载。

登录页使用原创动漫通信研究员插画，研究空间使用卫星小助手，配合 `frontend/src/SignalArtwork.tsx` 的天线、连续波形与理想 I/Q 星座图。`FormulaBackdrop.tsx` 在宽屏两侧展示香农容量、MIMO、BPSK/AWGN 误码率等公式；小于或等于 1400px 时隐藏，避免挤入正文。图像和公式只作装饰，不代表论文结果或运行状态；对辅助阅读技术隐藏，且不接收指针事件，不增加轮询或动画定时器。窄屏采用纵向布局和紧凑装饰，保持表单、搜索和下载可用。

界面采用本地托管的 Geng UI Rounded 圆体（Resource Han Rounded CN 的界面字符子集），三字重总计约 224KB，包含欢迎说明所需字形，使用 `font-display: swap`，动态论文标题缺字回退系统字体。两张透明 PNG、生成提示词和字体许可保存在 `frontend/src/assets/`；SIL OFL 许可同时随构建发布至 `/assets/rounded-font-license.txt`。插画由内置图像生成工具生成，字体及图片均不依赖外部 CDN。

## 最终 ZIP

```text
复现交付包/
  论文复现结果对比报告.docx
  本地复现报告.docx
  复现任务/
    t01_T1/
      代码/       源码、配置、依赖清单与必要输入
      复现结果/   本次已有图表、数据、指标等结果
      readme.md   运行说明及每个交付文件的用途
    t02_T2/
      代码/
      复现结果/
      readme.md
```

网站从内部完整 `repro_project/` 选择面向用户的交付文件，不合并任务实现、不重新执行实验、不重新判断 Reporter 结论。Writer 在已有 `task_agent_result.json` 中提供可选 `delivery_files`（相对路径、`code/input/result` 角色、简短用途），同时根据真实代码与结果撰写中文 `delivery_readme.md`，解释每个文件对应的信道、算法、实验或评价方法，以及各结果的比较对象、指标、符号与阅读用途。宿主只整理文件、保留必需运行文件，并把导读原样作为每个任务的 `readme.md`；不通过源码 docstring、CSV 列名或 JSON 字段自动生成科研说明。没有导读的旧案例可沿用已有人工说明；未说明的科学文件明确标记待补充，不因此阻断交付或重跑论文。

`代码/` 和 `复现结果/` 内部各自保持原有相对路径；先进入 `代码/` 再执行原命令，新运行仍写入原程序约定的输出路径。若已有结果也是运行输入，代码目录保留所需原路径副本。报告图片嵌入 Word。审计记录、执行收据、模型交接文件、临时调试文件、日志、虚拟环境和缓存都不进入下载包。原论文图页仅在代码确实需要它作为输入时保留。内部案例、证据与工作区不删除。

流程返回完整交付后再创建 ZIP；未复现的科学结论不妨碍完整交付。`partial`、`blocked`、异常或取消保持未完成状态，不提供“最终交付包”。打包只要求两份报告及项目文件存在并可读取，不增加科学语义或智能体 JSON 结构验收。文件路径必须位于本案例内，不跟随外部符号链接或 Windows junction。

ZIP 以运行 ID 命名，写入临时文件后原子替换。打包失败会记录 `pipeline_complete`；用户再次处理时只重建 ZIP。主流程文件和日志不删除。尚未成功的作业、其他用户的 ZIP 和任何任意路径都不能通过下载接口读取。

## 接口

| 接口 | 说明 |
|---|---|
| `POST /api/v1/auth/register` | 注册并登录 |
| `POST /api/v1/auth/login` | 登录 |
| `GET /api/v1/auth/session` | 当前账号和 CSRF token |
| `POST /api/v1/auth/logout` | 使当前会话失效 |
| `GET /api/v1/site` | 上传大小、是否开放注册 |
| `GET /api/v1/health` | 最小健康状态，无目录或队列内部信息 |
| `GET /api/v1/cases` | 仅当前账号的论文任务 |
| `POST /api/v1/cases` | 上传 PDF 并启动后台处理 |
| `GET /api/v1/cases/{id}` | 简单状态和最终下载地址 |
| `POST /api/v1/cases/{id}/retry` | 恢复未完成任务，或仅重试打包 |
| `POST /api/v1/cases/{id}/cancel` | 请求停止 |
| `GET /api/v1/cases/{id}/download` | 下载完成的最终 ZIP |

除登录相关公开端点、站点配置及健康检查外，浏览器数据接口都要求登录。未登录返回 401；访问其他账号或无归属的案例返回 404。登录后的写操作要求 `X-CSRF-Token`，并检查浏览器的请求来源；会话 cookie 为 HttpOnly、SameSite=Lax。密码使用带随机盐的 scrypt；数据库不保存明文密码或原始会话 token。认证限频保存于数据库，适用于多个 Web 进程；默认每邮箱 15 次、每客户端 IP 100 次 / 15 分钟。

pull 模式另外提供 `/api/v1/worker/claim` 和 `/api/v1/worker/jobs/{job_id}/{heartbeat,paper,complete,finish}`。这些接口使用独立 Bearer token，不接受普通用户会话作为工作机身份。领取在数据库事务中完成，同一工作机保留原案例归属；心跳过期不自动杀进程或重新派发。上传只处理 ZIP 文件传输、路径与存储上限，不解析报告内容或重做科研判断。取消与完成更新采用并发保护，成功任务不会被晚到的取消请求倒退。

## 数据与旧版本兼容

案例与作业沿用已有数据库表，新增账号、会话、认证尝试及工作机任务归属表。不删除旧事件、产物索引、导出记录和作业阶段列；运行时代码不再使用这些历史数据。旧案例 `owner_id` 为空时保持本地私有，不通过注册、导入或接口自动认领，也不会在新版网站启动时自动恢复运行。历史案例归属需要管理员另行明确处理。

`init_database()` 以新增表的方式兼容本地 SQLite。Alembic 提供 `0002_accounts` 和 `0003_pull_workers` 迁移。数据库及论文、ZIP 等运行文件均存放在公开静态资源目录之外。

## 运行与配置

本地仍使用 `start-web.ps1` 或 `geng-agent-web`，默认 `127.0.0.1:8765`。发布页面来自 `frontend/dist/`；修改源码后执行前端 build。前端开发端口为 5173，代理 `/api` 至 8765。

| 环境变量 | 默认与用途 |
|---|---|
| `GENG_CASES_ROOT` | 沿用主项目案例目录 |
| `GENG_DATABASE_URL` | 默认案例根目录内 SQLite |
| `GENG_REDIS_URL` | 默认 `redis://127.0.0.1:6379/0` |
| `GENG_CELERY_EAGER` | SQLite 默认进程内执行；外部 worker 设 0 |
| `GENG_EXECUTION_MODE` | 默认 local；pull 表示只由远端工作机领取，服务器不导入科学流程或 Celery |
| `GENG_WORKER_TOKEN` | pull 模式工作机专用凭据，服务器与本地配置必须一致 |
| `GENG_MAX_BUNDLE_BYTES` | ZIP 回传上限，默认 2 GiB |
| `GENG_MAX_PDF_BYTES` | 默认 80 MiB |
| `GENG_COOKIE_SECURE` | 本机 HTTP 为 0；公网 HTTPS 必须设 1 |
| `GENG_SESSION_DAYS` | 默认 7 天 |
| `GENG_REGISTRATION_ENABLED` | 默认 1；设 0 可停止开放注册 |

当前完成的是网站功能基础。邮箱作为登录标识，尚无验证码、邮箱所有权验证和密码找回。未提供计费、用户配额或管理员界面。

公网部署使用 HTTPS 反向代理、正确转发的 Host/协议及请求体大小限制。`deploy/web/` 提供仅安装网站依赖的 requirements、独立 systemd 服务和 Nginx 配置；pull 模式不需要云端科研环境或 Redis。原本的本机进程内模式只运行一个 Web 服务进程，避免重复恢复作业。本地科学代码运行权限沿用原项目；网站账号权限隔离不提供操作系统级的科学任务隔离。工作机配置与断网恢复说明见 [本地工作机说明](local_web_worker.md)。

## 验证

`tests/test_web_portal.py` 覆盖注册登录、会话过期与注销、CSRF、用户隔离、上传、最终包内容、打包恢复、取消和旧数据库保留。科学流程以模拟对象替代，不调用付费模型；这些测试证明网站交接与下载行为，不证明真实论文复现能力。前端测试覆盖接口会话处理和最终交付展示。

`tests/test_web_pull_worker.py` 覆盖原子领取、工作机归属、恢复、取消竞态与结果回传；`tests/test_local_web_worker.py` 覆盖断网、完成标记、文件锁和上传失败恢复。上线联调用模拟科学流程穿过真实云端与本地传输接口，并核对最终 ZIP 的哈希及两份 Word 是否可读。
