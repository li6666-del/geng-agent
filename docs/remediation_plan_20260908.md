# 实际论文运行问题整改计划

依据：2026-09-08 Rayleigh/BPSK/M-QAM 实际运行观测。目标是让 Reporter 承担科学判断，宿主承担证据身份检查、协议交接与调度。原始 case、日志和收据保持不变。

| 顺序 | 改动 | 验收 |
|---|---|---|
| 1 | Reporter 明确输出科学结论、直接理由、比较依据和下一步动作；删除宿主语义比较与通用倍率裁决；工程故障独立记录；旧判决缓存失效 | 等义表述和倍率不会改写 Reporter 判决；缺失交接只进入 Reporter 修复；无可信 full 不发布成功 |
| 2 | 缩短 IPC 路径、区分执行和回传状态；客户端检查匹配请求、宿主存活与失败状态；从原始收据恢复回传 | 中文长路径、回传失败、宿主退出、重复请求测试；恢复通知不重复科学执行 |
| 3 | 最终冻结保留已验证依赖导出；验证绑定运行相关文件；只有相关变化才失效 | 二次冻结不丢传递依赖和验证记录；代码/依赖变化使旧环境验证失效 |
| 4 | 报告固定呈现 Reporter 原判和理由、宿主工程状态；独立传递本地图和论文图；提供未选图的清单 | 不把交接/执行故障解释成论文信息不足；无论文裁图仍显示已选本地图；派生绘图不冒充 full |
| 5 | Foundation 按共享模块范围阅读，避免重复强制全量上下文；公开阶段进度与实际模型/执行耗时归因 | 上下文保留原文按需访问；用量未知不记作零；不因只改说明要求重复科学测试 |

验证顺序：针对性单元/集成测试 → 相关已有测试 → 本地完整测试集（不可用依赖如实记录）。使用仓库外临时目录和现有 Python 环境，不调用真实模型，不重跑真实论文。

科学阶段合并和模型编辑默认化属于后续对照实验：须比较主张覆盖、科学错误识别、耗时与用量，不能以模拟测试代替真实论文能力验证。本轮先完成有直接运行证据支持的精简。

## 本轮实现

1. **程序不再替 Reporter 判科研对错。** `verification_result.py` 接收 v3 明确判决、理由、比较依据和下一步动作；`scientific_materiality.py` 删除通用十倍验收政策。程序检查任务身份、交接字段和证据身份，不比较条件描述是否逐字相同，也不推导数值偏差是否重大。Reporter 可用原文纠正 Designer 的验收依据，并保留独立发现。成功发布仍要求可信 full、完整交接和 Reporter 已完成审查；未完成其重跑要求不能转成成功。
2. **算完但收不到通知，不再一直等或重算。** `execution_receipts.py`、`execution_client.py` 使用短临时文件名、Windows 长路径 I/O、按请求编号保存状态和独立心跳。回传失败时保留执行收据，客户端读取同一收据；宿主退出或心跳失效返回工程故障。原子落盘和依赖探测中的中文路径问题一并处理。
3. **最后打包不再冲掉已验证环境。** `delivery_environment.py` 根据声明、锁文件和导出文件哈希复用依赖闭包；`task_writer_packaging.py` 将环境验证绑定代码、配置、数据及检查点等文件。报告状态更新可复用，运行输入变化则撤销旧验证资格。不能证明环境可重建时如实记录，不改写论文结论。
4. **报告保留真正的理由和已有图。** `report_facts.py` 固定呈现 Reporter 原判、直接理由、工程状态和执行记录；本地图与论文图分别交付。Reporter 没选图时将现有本地图标为未核验的展示附件，不增加科学证据资格。补画图不能支撑 full 结论，也不能否定另有可信原始数据支撑的结论。
5. **先减少有证据的重复工作，并把耗时记清。** Foundation 首先读取共享模块范围内的上下文，原文和完整架构按需访问；只改结果说明不要求重跑测试。CLI 显示阶段进度，成本记录包含模型角色、会话、已知/未知用量及 smoke/full 执行耗时。并发会话耗时不直接相加冒充总耗时。

## 修改代价与边界

- v3 是判决协议升级。Reporter 提示词及科学处理代码纳入缓存身份，旧审查缓存不会直接成为新协议下的有效审查。历史 case 不自动改判，也不通过迁移脚本伪造新的 Reporter 判断。
- 取消宿主语义裁决后，等义条件、倍率意义、抽样不确定性与假设是否重大由 Reporter 负责。离线测试只能确认程序忠实传递这些决定，不能证明 Reporter 判断正确。
- 保留执行收据、文件哈希、独立审查证据快照、可信 Foundation 验证和交付环境验证。这些机制各自证明不同事实，本轮未为了减少调用而删除它们。
- 完整性修复复用原有 Reporter 修复路径，不增加 Agent 或新的科研重试层。工程交接问题不得让 Writer 为“过关”修改科学实验。
- 最终报告的固定记录可防止编辑器删掉原判；正文是否准确解释科学原因仍需真实模型对照检查。
- 长路径修复覆盖 IPC 及公共原子写入；本轮测试同时发现过深的临时目录会触发其他旧目录创建代码的 Windows 限制。完整测试使用仓库外短临时根目录，不声称所有任意深度路径均已支持。
- 测试依赖安装在仓库外现有 Python 环境；原始 case、日志、结果、检查点和执行收据未改写。该环境增加了测试依赖，后续真实复现须重新记录环境身份。
