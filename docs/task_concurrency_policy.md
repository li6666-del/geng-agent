# 任务并发的科学边界

Writer 的调度单位是 execution unit，Reporter 的验收单位是科学任务。不同任务默认由独立 Writer 并发处理；需要相同冻结公式、确定性系数、网格、参考实现或指标定义时，用 weak 关系和 Foundation 保持一致。共同图号、复用 CSV 或少算一次确定性函数本身不构成 strong。

真实的同次联合观测、精确检查点、成对随机样本或实际数据划分仍使用 strong。当前编译器将 strong 连通任务交给同一 Writer，并在其中按产物流顺序执行；这是保留科学依赖的边界，不能承诺所有论文的全部 Writer 同时运行。将来若要让同一检查点的多个消费者并发，需要单独实现带哈希和失效传播的跨执行单元产物传递，不能直接删除 strong 边。

规划智能体在现有一次规划中解释每条 strong 必须相同的状态、科学依据，以及共享冻结实现为什么不足。宿主只编译声明，不通过关键词猜测、自动降级或改写已接受的科学关系。联合规划中尚未定稿的关系可以一起修正；独立架构阶段必须遵守已定稿关系。历史案例和缓存中的强关系不会因提示词更新被悄悄修改。

回归验证涵盖：共同图号和 weak 定义不合并 Writer；真正的检查点和共同样本依赖仍保留；混合依赖保留独立任务；未声明依赖时不按任务措辞推断；存在显式强关系时不按 rationale 反向删除。提示词检查验证真实联合规划入口收到这些规则。此类本地测试不证明模型一定正确选择关系，真实论文的规划结果仍需观测。

## 运行与恢复

- 不同执行单元先全部提交，再等待结果。一个单元完成 Writer 后即可进入 Reporter，无需等其他单元的 Writer 完成。
- 同一复合执行单元的逻辑任务分别启动 Reporter；首次执行、继续执行与缓存重审共用并发审查函数。所有 Reporter 完成后才把反馈写入共享 Writer 目录，随后才允许 Writer 修订。
- 完整和部分恢复都调用 Reporter 自身的缓存检查。旧判决已经终结不代表当前提示词、输入或报告资源仍然有效。缓存有效时不会启动模型，缓存失效只重做必要的审查。
- 部分恢复中的缓存审查与其他未完成 Writer 同时调度；它直接使用已经验证的 Writer 记录，避免为检查 Reporter 缓存先重建 Writer 目录。需要因果修订时只重放旧审查一次，修订后的审查使用新输入。
- 单个审查失败保留该任务的 Writer 交付与其他审查结果，但撤销旧科学判决及 matched 标记。执行单元内真实的检查点和运行状态依赖仍由该 Writer 按依赖执行。
- 每次工作流开始时固定宿主执行策略的源码指纹；结束时仍补充实际运行依赖。运行中编辑宿主源码不会污染本轮缓存身份，下次工作流会重新读取策略。

## 如何确认实际并发

`03c_task_writers_start.json` 的 `agent_concurrency` 表示计划中的 Writer 单元数。真正的模型会话数见 `audit/agent_activity.json`，历次运行保存在 `audit/agent_activity_runs/`：

- `active`：当前 Writer、Reporter 与总会话数。
- `peak`：本轮实际启动会话的峰值。
- `sessions`：独立调用的角色、标签、工作目录、起止时间和状态。
- `cached`：复用次数，不计入启动会话或峰值。

CLI 与现有 Web 事件流会收到 `agent.started/completed/failed/cached`，事件文本包含当前两类会话数。计划中有五个任务，不等于任何时刻都应该有五个进程；依赖、缓存和各任务时长都会影响实际数量。强制杀死整个宿主进程可能留下最后一帧运行状态，应结合进程存活与下一轮历史记录判断。

`test_task_agent_process_concurrency.py` 通过真实本地子进程及文件屏障验证调度与工作区隔离；`test_agent_activity.py` 验证运行计数；`test_task_concurrency_resume.py` 验证恢复和反馈屏障。这里的本地替身不调用模型，也不代表 DeepSeek 服务端处理能力或论文复现质量。外部提供商限流、主机 CPU/GPU 资源压力仍需在真实运行中观测。

需要检查真实提供商连接时，可显式执行 `tools/probe_task_agent_concurrency.py --config <项目模型配置.json> --output <项目外的新目录>`。它仅启动 2 个 Writer 与 2 个 Reporter 会话，各自执行一个预置标准库脚本；这会调用模型，但不跑论文。没有持久化密钥时加 `--prompt-key`，隐藏输入只用于本次进程。诊断拒绝覆盖非空目录，并将真实命令、固定输出标记、脚本哈希、统一模型配置及会话重叠检查写入 `summary.json`。诊断成功也不代表提供商内部计算同时进行，或真实论文的科学依赖规划正确。
