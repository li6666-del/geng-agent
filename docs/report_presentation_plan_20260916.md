# 最终报告清晰度与排版改进

## 目标与边界

两份中文报告继续由最终 Editor 撰写。结果对比报告帮助读者判断各任务的结果与差距；本地复现报告帮助读者查找运行方法、实现条件和执行证据。程序只负责结构化材料、确定性的版式转换，不生成叙述、不改写数值或科学结论、不增加审查轮次。

保留任务目标边界、论文事实与补充假设的区别、失败与不确定性。历史论文案例和已有报告保持原样。

## 实施计划

1. 调整 Editor 输入与写作约定：任务总览、结论先行、关键差距短表、具体人工核查建议；技术报告按运行入口、环境和共享实现、任务细节、记录与索引排列。保留已核实状态，不自动推断总体通过率。
2. 改进图片组织：提供像素尺寸作版式参考；简单相似图可并排，宽图、多面板及整页材料上下全宽展示；同一原文页集中引用，不同结果分支全部保留。优先已有图裁剪，不新增自动裁图或科研重跑。
3. 改进 Word 转换：单一标题、清楚的标题层级、合理留白、细线表格、数字对齐、页码、可点击链接和代码块；图片保持比例并受页面宽高限制，图注跟随图片。去除默认正文截断与自动补写声明。
4. 用上次真实材料编辑独立样稿，保留历史审查结论；在项目外生成并渲染 Word，检查每页的图片、表格和分页，同时运行相关回归测试。

## 验证重点

- Editor 仍接收 Reporter 唯一判决与已核实事实；范围外发现单独保留。
- 图像布局变化不改变原图片字节或对照关系，未提供图像时继续清楚说明缺失。
- 长段落、完整精度、长路径与代码文本不被静默截断。
- Markdown 和 Word 都保留智能体正文；标题不重复，不额外追加报告正文。
- 普通表格重复表头，图片不越过页面，图与图注不分离。
- 样稿只是历史材料的编辑排版验证，不算新的论文实验或新政策下的科学重审。
