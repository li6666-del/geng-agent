# 智能体合并实施计划

目标：将科学流程收敛为论文理解、实验规划、Writer、独立 Reporter 四类职责，末尾保留已有的 Report Editor 负责中文报告。减少重复阅读，同时保留原文证据、任务依赖、执行收据和可恢复交付。共享 Foundation 继续按跨执行单元的真实复用需要启用。报告部分已按后续用户要求修订，原程序报告方案已撤回。

| 步骤 | 修改 | 验收 |
|---|---|---|
| 1 | 事实提取与核心主张合并为论文理解阶段，分别发布事实和主张文件；缺口回补作为理解角色的定向能力 | 初始规划已收到主张；事实、推导及假设身份不混淆；缓存与失败恢复保留分开的证据文件 |
| 2 | 初步任务、最终验收依据和科学架构由实验规划阶段共同产生；有关键缺口时定向回补再修订 | 无缺口路径只有理解、规划两次主要分析调用；回补后任务与架构同步；不再额外提炼主张、重新定稿、单独调用架构模型 |
| 3 | 清理设计提示词中宿主负责数值阈值的旧规则 | 程序只检查交接和工程证据；科研可比性、重大偏差及复现结论仍归 Reporter |
| 4 | Reporter 提供核验解释；已有 Report Editor 默认撰写报告，清理 Python 报告模板 | 报告按任务说明事实、假设、图片对比、差距和人工核查建议；工程细节放入本地复现报告；缺失文件只交给同一 Editor 补写 |
| 5 | 保留 Writer/Reporter 隔离与跨执行单元 Foundation；验证 CLI/Web 共用路径及旧 case 恢复 | 不新增 Agent 或科研重试层；旧缓存不能绕过新协议；私有代码与共享代码所有权不变 |

实施约束：不修改三个本机启动脚本，不改写历史 case，不运行真实模型或真实论文。测试、生成产物在仓库外现有环境和临时目录中进行。先跑针对性回归，再跑必要的完整测试。真实论文的主张覆盖、科学错误识别和成本变化需另做对照实验。

Codex 合并阶段采用同一调用写多个约定文件，避免要求模型在末条消息一次输出所有大型文档；API JSON 后端保留结构化组合协议。程序验证结构和引用，保留独立文档与缓存身份，不据自然语言相似度替模型作科学判断。

## 已完成的修改

- 默认前半段改为 `01_understand_paper` 与 `02a_plan_experiments`。没有回补和 JSON 修复时，原先事实、初步任务、主张、最终任务、架构的五次主要调用缩为两次；实际 token 和耗时不据此推算。
- 定向回补沿用原搜索台账与停止规则；修订由同一实验规划角色联合产出任务和架构。按已有任务 ID 保留被遗漏的目标，新的依赖图替换旧图，不把旧关系累加回新计划。联合计划的新任务不因缺少“Fig.”类文字模式而被程序删除。
- 保留架构中原有的修复保护：允许修复明确报错的字段，不允许借 JSON 修复修改其他单位、参数或归一化。Codex 在独立工作目录写多份 JSON，同一次阶段尝试内可修复缺失/损坏文件，已完成的文件仍在原位置；未声称跨中断调用复用未经完整验证的部分文档。
- 默认调用已有 Report Editor，旧 `GENG_REPORT_MODE` 开关及程序报告实现已移除。Reporter 的独立结论和已核验材料供 Editor 编写两份中文详细报告与一份简短导航；Python 只处理证据传递、图片恢复、文件安全和 Word 转换。旧材料不足时说明不足，不能用任务计划补造科学事实。
- 无缺口和已完成回补的恢复均复用匹配的组合缓存；`cache_reused` 等运行标记不进入科学提示词。主机能力变化只使规划失效；论文变化使理解和规划失效；显式架构重启清除联合规划缓存。旧分阶段缓存不冒充新协议结果。
- Writer 与 Reporter 继续隔离；Foundation 的跨执行单元冻结与私有代码边界沿用原实现。CLI/Web 仍共用 ReviewPipeline，未另设两套编排流程。README 和进度阶段归属已同步。

## 后续报告方案调整验证

恢复已有 Editor 为默认报告阶段并清理程序兜底后，全量测试 846 passed、16 skipped、177 subtests passed。随后删除两份未调用的旧 Markdown/Word 模板及其两个专属测试，清理遗留兜底状态分支，相关专项测试 66 passed、2 subtests passed。未在此次报告调整中调用真实模型；模拟 Editor 的测试验证材料传递、图片恢复、缺文件修复和正文不被程序改写，不能证明真实报告质量。

仍需真实论文对照实验回答：合并理解是否降低关键条件召回，联合规划在大论文上的输出规模与修复次数，面对训练、方法排序不稳定和数值不可比时的实际判断质量，以及真实 token、费用与总耗时是否下降。默认 Editor 会产生报告编辑调用，其事实忠实度、图文对应质量和成本需通过真实交付评估。
